# MeetLens MVP 要件定義

## 概要
会議の品質を分析・可視化するWebアプリケーションのMVP。
VTTファイルをアップロードし、議事録自動生成と品質スコアリングを行う。

参照: [meetlens-concept.md](../meetlens-concept.md)

---

## MVPスコープ

### Must（MVP必須）

#### 1. 認証・テナント管理
- Cognito によるログイン・サインアップ
- テナント分離（データ設計・認証にTenantIDを組み込む）
- テナント内のユーザー管理

#### 2. VTTアップロード
- .vttファイルのアップロード（Teams/Zoom/Webex対応）
- アップロード時のメタデータ入力:
  - 会議タイトル
  - 開催日時
- 会議タイプは画面では入力させず、データ上は「定例」として保持する（将来のタイプ追加に備える）

#### 3. 議事録自動生成
- VTTをパースし、LLM（Bedrock）で議事録を生成
- 日本語の音声認識誤りをLLMに文脈から補正させる

#### 4. 会議の質分析・スコア化
- 対応する会議タイプ: **定例** のみ

##### 定例の評価指標
| 指標 | 算出方法 |
|---|---|
| 意思決定数（明確な決定 / 保留・先送り / 未決） | LLM |
| アクションアイテムの具体性（担当者・期限の有無） | LLM |
| 脱線率 | LLM |
| 発言量の偏り | ルールベース（VTTの話者・時間から計算） |

#### 5. ダッシュボード・会議一覧
- テナント内の会議一覧表示
- 各会議のスコアサマリー・処理状態（処理中 / 完了）を一覧で確認

#### 6. 会議詳細表示
- 議事録の閲覧
- 分析結果・スコアの表示

### Out of Scope（MVP後に検討）
- ファクトチェック機能（Web検索API連携）
- HTML生成・ストック（フロントエンドで直接表示するため不要）
- 会議タイプ追加（1on1、デイリースクラム、ブレスト・ふりかえり）と、タイプごとの評価の重み付け
  - 1on1 は「部下の発言比率」のために上司・部下の判別が必要
- 時間あたりの議題消化率（議題の特定にアジェンダ事前登録が必要）
- トレンド分析（会議シリーズの品質推移）
- 会議シリーズの概念
- アジェンダ事前登録と消化率
- 通知・アラート
- VTT自動取得（Microsoft Graph API連携）

## 非機能要件

| 項目 | 方針 |
|---|---|
| 利用規模 | 数人・月数十件程度（同時アクセスはほぼ考慮しない） |
| AWS利用料 | 月1000円以下を目安とする |
| 分析処理 | 非同期（アップロード後は「処理中」を表示し、完了後に結果を表示） |
| VTT上限 | 1ファイル1MB程度・会議2時間程度まで |
| データ保持 | VTT原本・議事録・分析結果ともに無期限保持 |

技術スタック・LLMのモデル選定は [tech-stack.md](../tech-stack.md) を参照。
