# MeetLens MVP 要件定義

## 概要
会議の品質を分析・可視化するWebアプリケーションのMVP。
VTTファイルをアップロードし、議事録自動生成と品質スコアリングを行う。

参照: [meetlens-concept.md](../meetlens-concept.md)

---

## MVPスコープ

### Must（MVP必須）

#### 1. 認証・テナント管理
- Cognito によるログイン・サインアップ
- テナント分離（データ設計・認証にTenantIDを組み込む）
- テナント内のユーザー管理

#### 2. VTTアップロード
- .vttファイルのアップロード（Teams/Zoom/Webex対応）
- アップロード時のメタデータ入力:
  - 会議タイトル
  - 会議タイプ（定例 / 1on1）
  - 開催日時

#### 3. 議事録自動生成
- VTTをパースし、LLM（Bedrock）で議事録を生成
- 日本語の音声認識誤りをLLMに文脈から補正させる

#### 4. 会議の質分析・スコア化
- 会議タイプに応じて評価の重み付けを変える
- 対応する会議タイプ: **定例** / **1on1**

##### 定例の評価指標
- 意思決定数（明確な決定 / 保留・先送り / 未決）
- アクションアイテムの具体性（担当者・期限の有無）
- 脱線率
- 発言量の偏り
- 時間あたりの議題消化率

##### 1on1の評価指標
- 部下の発言比率（7割以上が理想）
- アクションアイテムの具体性
- 新規論点・アイデアの検出

#### 5. ダッシュボード・会議一覧
- テナント内の会議一覧表示
- 会議タイプでのフィルタリング
- 各会議のスコアサマリーを一覧で確認

#### 6. 会議詳細表示
- 議事録の閲覧
- 分析結果・スコアの表示

### Out of Scope（MVP後に検討）
- ファクトチェック機能（Web検索API連携）
- HTML生成・ストック（フロントエンドで直接表示するため不要）
- 会議タイプ追加（デイリースクラム、ブレスト・ふりかえり）
- トレンド分析（会議シリーズの品質推移）
- 会議シリーズの概念
- アジェンダ事前登録と消化率
- 通知・アラート
- VTT自動取得（Microsoft Graph API連携）

## 非機能要件

| 項目 | 方針 |
|---|---|
| 利用規模 | 数人・月数十件程度（同時アクセスはほぼ考慮しない） |
| AWS利用料 | 月1000円以下を目安とする |
| 分析処理 | 非同期（アップロード後は「処理中」を表示し、完了後に結果を表示） |
| VTT上限 | 1ファイル1MB程度・会議2時間程度まで |
| データ保持 | VTT原本・議事録・分析結果ともに無期限保持 |

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | Vue 3 + TypeScript + Vuetify |
| バックエンド | Python Lambda |
| AI/LLM | Amazon Bedrock |
| 認証 | Amazon Cognito |
| データベース | Amazon DynamoDB |
| ファイルストレージ | Amazon S3 |
| IaC | SAM（サーバーレス部分）/ Terraform（基盤部分） |
| CI/CD | GitHub Actions |
